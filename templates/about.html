About the Project

A privacy-preserving liver tumor segmentation system combining MedSAM, SANet, and Federated Learning for automated medical image analysis while keeping patient data local.

Vision Transformer

MedSAM and SANet are used for automated liver tumor segmentation.

Federated Learning

Enables collaborative training without sharing patient medical images.

PET–CT Dataset

Multimodal PET–CT images are used for liver tumor segmentation.

Tumor Analysis

Provides tumor detection, confidence, severity, and segmentation metrics.

Technologies Used

Component Technology
Frontend HTML, CSS
Backend Python Flask
Deep Learning PyTorch
Segmentation MedSAM + SANet
Federated Learning Flower Framework
Evaluation Dice Score, IoU, Precision, Recall
Privacy Focus: Patient medical images remain local during federated training.
