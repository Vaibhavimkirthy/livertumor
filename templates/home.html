Liver Tumor Detection Using Vision Transformer and Federated Learning

This project detects liver tumors from PET-CT scan images using Vision Transformer (MedSAM + SANet) with Federated Learning (Flower Framework).

Vision Transformer

Medical image segmentation using MedSAM and SANet.

Federated Learning

Train models across hospitals without sharing patient data.

PET–CT Dataset

Multimodal PET–CT images for liver tumor segmentation.

Evaluation

Dice Score, IoU, Precision and Recall.
